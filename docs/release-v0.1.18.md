# Tales of Seikyu Korean Patch v0.1.18

Steam Windows build `24948693`용 번역 폴리싱 릴리즈입니다.

- 전체 스크립트 23,500행을 장면·표 단위로 검토하고 4,955행을 다듬었습니다.
- 인물의 말투·호칭, 이름·조사, 선택지와 반응, 오역·누락·직역투를 수정했습니다.
- 누락 원문 24행을 추가 반영해 총 22,555행을 적용합니다.
- 기존 UI·가방 폰트 연결과 가방 정렬 버튼의 영어 우회 표시를 유지합니다.

## 설치

1. 아래 ZIP을 받아 압축을 풉니다.
2. 게임을 완전히 끄고 새 `TalesOfSeikyuKoreanPatch.exe`를 실행합니다.
3. `한국어 패치 설치/업데이트`를 누릅니다.
4. 게임을 켜고 설정에서 언어를 **일본어(日本語)**로 바꾼 뒤 변경을 적용합니다.
   언어 항목이 `Korean`으로 표시되면 그 항목을 선택하세요.

**영어를 선택하면 한국어 대사가 나오지 않습니다.** 일본어 자리에 한국어를 넣는 패치입니다.
기존 사용자도 새 패처로 설치/업데이트해야 이번 수정이 반영됩니다.
제거할 때는 패처의 `원본 복구`를 사용하세요.

## 확인 범위

최종 ZIP에서 꺼낸 EXE로 깨끗한 원본 설치·검증·정확 복구와 v0.1.17 덮어 설치를
통과했고, 두 경우 모두 22,555행을 번들에서 다시 읽어 일치를 확인했습니다.
실제 로컬 게임에도 적용한 뒤 전체 문구 일치와 15초 기동을 확인했습니다.
도구 회귀 검사 14개 스크립트(폴리싱 단위 테스트 65개 포함)와 Ruff 검사도 통과했습니다.
실제 화면의 글리프·줄바꿈·이벤트 분기 전수 플레이 검증은
별개이며 완료를 주장하지 않습니다. 이상이 있으면 스크린샷과 진단 리포트를 제보해 주세요.
가방 정렬 버튼 `Normal / Quest / Gold`는 글자 깨짐 방지를 위한 기존 우회 표시입니다.

게임 원본 번들·실행 파일·외부 폰트 파일은 배포하지 않습니다.
자세한 방법은 [설치 안내](https://github.com/yuniwon/tales-of-seikyu-korean-patch#readme)를 확인하세요.
