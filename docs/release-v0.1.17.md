# Tales of Seikyu Korean Patch v0.1.17

Steam Windows build `24948693` 대응 릴리즈입니다.

- 주요 문자열 표의 추가·삭제·원문 변경이 없어 기존 번역 22,531행을 그대로 유지했습니다.
- 현재 Excel 번들 해시를 정식 지원하도록 갱신했습니다.
- UI 폰트 별칭 95개, 가방 폰트, 가방 카테고리 표시 수정을 포함합니다.
- 원본 복사본에서 설치·검증·원본 복구 및 업데이트 호환 테스트를 통과했습니다.

ZIP 압축을 풀고 `TalesOfSeikyuKoreanPatch.exe`에서 `한국어 패치 설치/업데이트`를 누르세요.
기존 패처의 `최신 패처 확인`에서도 새 버전을 받을 수 있습니다.

이번 게임 빌드는 v0.1.16의 호환 모드에서도 모든 번역이 일치합니다.
이미 정상적으로 한국어가 나온다면 추가 번역을 위해 반드시 재설치할 필요는 없습니다.

실제 게임 화면에서의 폰트·줄바꿈·컷신 플레이 검증은 이번 작업에서 수행하지 않았습니다.
문제가 있으면 게임 빌드, 화면 위치, 스크린샷과 패처 진단 리포트를 함께 제보해 주세요.

설치·복구 방법과 전체 안내는 [README](https://github.com/yuniwon/tales-of-seikyu-korean-patch#readme)를 확인해 주세요.
